# Dashboards contribution

Create a JSON file in this folder from GitHub's web editor. Use a descriptive filename such as `signal-board.json`. Keep `category` set to `Dashboards`.

```json
{
  "title": "Concept name",
  "category": "Dashboards",
  "summary": "A short description of the fictional concept.",
  "audience": "Who this concept is for",
  "platform": ["Web"],
  "style": "Visual direction",
  "tags": ["topic", "pattern"],
  "palette": ["#112233", "#445566", "#F5F5F5"],
  "typography": "Suggested typefaces or type characteristics",
  "spacing": "Layout and spacing notes",
  "components": ["Component 1", "Component 2"],
  "user_flow": ["First step", "Next step", "Outcome"],
  "references": [],
  "fictional_concept": true
}
```

Submit the file in a pull request for review. It will not be published automatically.
