# Contribute to BITON

Add a fictional design concept through GitHub's website—no software installation is needed. You will need a GitHub account. Choose one category folder, open its `concept.json` link below, edit the suggested file in the browser, and use GitHub's prompt to create a pull request.

| Category | Start a contribution |
| --- | --- |
| Mobile Apps | [Create concept.json](https://github.com/adnqcr7-code/biton/new/main/contributions/mobile-apps/concept.json) |
| Websites | [Create concept.json](https://github.com/adnqcr7-code/biton/new/main/contributions/websites/concept.json) |
| Dashboards | [Create concept.json](https://github.com/adnqcr7-code/biton/new/main/contributions/dashboards/concept.json) |
| Components | [Create concept.json](https://github.com/adnqcr7-code/biton/new/main/contributions/components/concept.json) |

Use the JSON structure in the selected folder's README. Give your file a descriptive name if the folder already contains a `concept.json`. Pull requests are for review only: nothing appears in the live catalogue unless the maintainer accepts it and adds it to the catalogue.

Describe original ideas as fictional concepts. Do not submit fabricated screenshots, metrics, or claims about real products. Credit any real references and separate verified facts from your own ideas.
