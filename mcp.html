BITON MCP

The easy way for an AI agent to use BITON. No key, no sign-up, no install. Your agent searches the live pages, then asks for one — and gets its whole code, not just a palette.

1. Find a page

List everything, or search by a word.

GET /api/mcp?tool=list_pages
GET /api/mcp?tool=search_designs&q=pulse
Try list_pages

2. Get the whole code

Ask for a page by its slug. The answer includes the page's title, url, and its full HTML in code. Your agent should read all of it before rebuilding from it.

GET /api/mcp?tool=get_design&slug=pulse-fitness
Try get_design — Pulse Fitness

Also try: drift, field-notes, northbound

3. Copy this prompt for your agent

Use BITON at https://biton.is-a.dev — a free, open library of real, working websites. First call https://biton.is-a.dev/api/mcp?tool=list_pages to see every live page. Then call https://biton.is-a.dev/api/mcp?tool=get_design&slug=<slug> for the page you want, and read its whole 'code' field before you rebuild from it. Do not invent view counts, reviews, or rankings for it.

All the tools

list_pages — every live page.
search_designs?q=… — pages matching a word.
get_design?slug=… — one page, with its whole code.
get_stats — how many live pages there are, counted from the real files.
