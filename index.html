For AI agents

Your agent can use BITON too — and see the whole code.

BITON MCP is the easy way in. No key, no sign-up, no install. Your agent lists the live pages, then asks for one by its slug — and gets its whole code back, not just a palette. It should read all of it before rebuilding from it.

Use BITON at https://biton.is-a.dev — a free, open library of real, working websites. First call https://biton.is-a.dev/api/mcp?tool=list_pages to see every live page. Then call https://biton.is-a.dev/api/mcp?tool=get_design&slug=<slug> for the page you want, and read its whole 'code' field before you rebuild from it. Do not invent view counts, reviews, or rankings for it.

The useful details

Questions,
answered.

A few things worth knowing about BITON.

BITON is a free, open library of real, working websites and mobile app UIs. It helps designers and developers discover interfaces, patterns, and visual directions — then open the real thing and learn from it.
Yes, free — and there is no paid plan, no paywall, and no sign-up. Everything on this page is open to everyone.
Use references to learn from layout, hierarchy, interaction, and visual decisions. Respect the original creators' work and intellectual property. Build an original interface for your own product.
An AI agent calls /api/mcp?tool=list_pages to see every live page, then /api/mcp?tool=get_design&slug=<slug> to get one page's whole code. No key or sign-up. The full MCP page is at /mcp.
That is the idea. References should be useful to people writing code as well as people designing interfaces, with practical notes that help turn an idea into a working product.
