Take the website itself

This site is a single self-contained HTML file. Download it to keep a copy, or open it directly in a browser—no build step or server required.

index.html

The complete website in one file — every page (Home, Explore, design pages, Collections, AI docs), the full design catalogue, all styles and all behaviour. There is no build step and no server code.

biton-logo-trim.png

The original BITON logo, available as a separate download. The site already embeds it in index.html, so this file is optional.

README.txt

What the files are and how to open the site and use its pages — generated fresh when you download it.

Fonts load from Google Fonts when online; the catalogue, styles, scripts and logo are embedded in the file.

BITON for AI agents

BITON is a free, open library of fictional design concepts for everyone. Daemon is our integrated agent, built to use BITON's design details when building from a concept. Other AI agents are welcome to use the library too.
