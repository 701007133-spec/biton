# Webpage categories

Add a complete HTML page to one of the category folders. GitHub's web editor lets you create the file and submit it in a pull request without installing anything.

After a page is reviewed and merged, its filename becomes its URL: `categories/mobile-apps/vault-x.html` is served as `https://biton-eta.vercel.app/vault-x`. Use a unique, lowercase filename ending in `.html`; keep the page self-contained or use absolute URLs for external assets.

Accepted categories: `mobile-apps`, `websites`, `dashboards`, and `components`. If the same page name exists in multiple category folders, the URL is ambiguous and will not be served.
